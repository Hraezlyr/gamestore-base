# Store logos

Steam, Epic Games, GOG and Humble Bundle SVGs are vendored from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons)
under CC0-1.0; the upstream license is included in `LICENSE.txt`.

The UI uses local vectors so these marks remain sharp on high-density displays
and do not require third-party icon requests. Other stores use legible initials,
not enlarged low-resolution provider thumbnails. Store names remain on their
accessible action labels and offer cards. No game artwork is changed here.
An explicit SVG supplied by the API is preserved; bitmap thumbnails are replaced.
